## 📦 О проекте

**e8unpack** — консольная утилита для работы с контейнерными файлами 1С:Предприятие (`.cf`, `.epf`, `.erf`, `.cfe` и другими). Позволяет распаковывать контейнеры в каталоги с сохранением структуры метаданных, выводить список элементов и собирать новые контейнеры обратно из каталога.

Утилита написана на **C++17** с использованием **Qt 6** (Core) и собирается под **Linux** (GCC) и **Windows** (MinGW). Windows-версия — **полностью статическая**: один `.exe` без внешних DLL.

## ✨ Возможности

- 📂 **Распаковка** контейнеров `.cf`, `.epf`, `.erf`, `.cfe` в каталог
- 🗂️ **Раскладка по метаданным** — файлы размещаются по человекочитаемой структуре с использованием JSON-карты метаданных
- 📋 **Просмотр содержимого** без записи на диск (режим `--list`)
- 📦 **Обратная сборка** контейнера из каталога
- 🗜️ **Управление сжатием** — опциональное отключение deflate при сборке
- 🖥️ **Кроссплатформенность** — Linux и Windows из одного исходного кода
- 🚀 **Статический Windows-билд** — никаких внешних зависимостей, никаких DLL рядом с `.exe`

## 💾 Установка

### Готовые сборки

Скачайте последний релиз со страницы **[Релизы](https://github.com/e8tools/v8unpack/releases)**:

| Платформа | Файл | Примечание |
|-----------|------|------------|
| **Linux x86_64** | `e8unpack-<версия>-linux-x86_64.tar.gz` | Требуется Qt6 в системе |
| **Windows x86_64** | `e8unpack-<версия>-windows-x86_64.zip` | Полностью автономный `.exe` без зависимостей |

### Linux

```bash
tar -xzf e8unpack-*-linux-x86_64.tar.gz
chmod +x e8unpack
./e8unpack --help
